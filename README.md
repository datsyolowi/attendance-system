# Attendance System

A modern web-based attendance and daily time record (DTR) system built with Next.js and Supabase.

Designed for offices, small businesses, schools, and organizations that want a simple, fast, and digital employee attendance solution using PIN authentication.

---

## Features

- PIN-based employee attendance
- Time In / Time Out logging
- Real-time attendance storage
- Tablet-ready kiosk interface
- Responsive modern UI
- Supabase cloud database
- Fast and lightweight
- Easy deployment
- Scalable architecture

---

## Tech Stack

### Frontend

- Next.js 16
- React
- Tailwind CSS
- TypeScript

### Backend / Database

- Supabase
